# Gestor Financeiro Pessoal — Versão Definitiva 100% Completa (PWA)

Todos os módulos, gráficos, logos SVG e regras de negócio do sistema original em Python foram integralmente migrados:
- `js/logos.js`: Logos vetoriais embutidos (Santander, Nubank, Mercado Pago, Magalu, etc.).
- `js/charts.js`: Gráfico de tendência com curva suave Catmull-Rom e barras de limite.
- `js/database.js`: Todas as 17 stores (incluindo `mov_metas`, `qmd_parc`, `conc_sessoes`, `conc_extrato`, `conc_match`, `conc_hist`).
- `js/services.js`: Motor matemático completo, hashes idempotentes e cálculos de reserva de metas.
- `js/ui1.js` a `js/ui5.js`: Todas as 17 telas operacionais, com preset nativo para o arquivo do Kontto.
